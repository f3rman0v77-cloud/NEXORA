# Futbol bölməsi
- Mənbə: yalnız ESPN (açar lazım deyil). Backend `api/football.js`; işləməzsə brauzer `football-direct.js` ilə birbaşa çəkir.
- Katalogda yalnız ESPN-in həqiqətən cavab verdiyi turnirlər qalır.
- Diaqnostika: `/api/football?action=health`

# Mərc sistemi (Supabase)
1. Supabase Dashboard -> SQL Editor -> `supabase-betting.sql` faylının məzmununu yapışdırıb Run edin (bir dəfə).
2. Balans və mərclər artıq brauzerdə yox, hesabda (Supabase) saxlanılır. Mərc üçün hesaba daxil olmaq lazımdır.
